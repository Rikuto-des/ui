Item と Drawer の比較

Item と Drawer の見た目

新しく足す 2 つの部品を、それぞれ 3 つの形で作りました。パックとテーマは上の切り替えで変えられます。

Item（一覧の 1 行）

アイコン・題・説明・操作を 1 行にまとめる部品です。同じ設定画面の 3 行を、3 つの形で並べました。3 行目はリンクの行で、押すと別の画面へ移る想定です。

おすすめは A です。設定や一覧で一番よく使う形で、行の種類が混ざっても揃って見えます。Card の中に置くときは C の形（枠なし）を指定で選べるようにします。

良い点
設定画面で一番よく見る形。まとまりが一目で分かり、行が多くても線で追える。iOS の設定や GitHub の設定と同じ並び。
気になる点
枠の中に Card を入れるなど、枠が重なると窮屈に見える。
作り
一覧（Item.Group）に枠線と角丸を付け、行の間に線を引く。リンクの行だけホバーで背景が付く。

Drawer（下から出して引いて閉じるシート）

「予定を追加」を押すと、下からシートが出ます。シートを下に引くと閉じます（マウスでもドラッグできます）。中身は今の Sheet と同じ dialog です。

おすすめは A です。スマホで見慣れた形で、導入の手間も増えません。B の後ろが下がる演出は、あとから選べる指定として足せます。

A つまみ付き

今日の予定

10:00 デザインの確認

13:30 週次の打ち合わせ

16:00 リリースの準備

予定を追加
良い点
上のつまみで「下に引ける」と分かる。iOS・Android の標準のシートと同じ見た目で、スマホで見慣れている。
気になる点
つまみは飾りなので、キーボードやスクリーンリーダーでは閉じるボタンか Esc が別に要る（中の「やめる」がその役）。
作り
Sheet（下から）の上端につまみを付け、上の角を大きめに丸める。下に引くと指について動き、4 分の 1 を超えるか素早く払うと閉じる。

B つまみ＋後ろが下がる

今日の予定

10:00 デザインの確認

13:30 週次の打ち合わせ

16:00 リリースの準備

予定を追加
良い点
後ろの画面が少し縮んで奥に下がり、重なりがはっきりする。vaul（shadcn/ui の Drawer）と同じ演出。
気になる点
後ろの画面を縮めるには、ページの一番外側に印を付ける必要があり、導入の手間が 1 つ増える。動きが大きいので好みが分かれる。
作り
A に加えて、開いている間は後ろの画面を 96% に縮めて角を丸める（動きを減らす設定では縮めない）。

C つまみなし、閉じるボタン

10:00 デザインの確認

16:00 リリースの準備

予定を追加
良い点
閉じ方が目に見えるので、パソコンでも迷わない。今の Sheet（下から）とほぼ同じで、違いは引いて閉じられることだけ。
気になる点
引いて閉じられることに気づきにくい。
作り
Sheet（下から）のまま、右上に閉じるボタンを置く。下に引いて閉じる動きは A と同じ。
