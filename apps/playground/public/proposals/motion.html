速さ

状態が変わるときの動き

左が今の動き、右が候補です。どちらも実際に操作できます。上のバーで、パック・テーマの切り替えと、ゆっくり再生ができます。動きはすべて CSS で、速さと動き方はパックのトークンに従います。

1. Checkbox：印を書くように出す

今
チェックの印が、少し小さい状態から拡大しながら現れる。
候補
印が左から右へ、書くように現れる（clip-path）。外すときは、速く消える。
ブラウザ
Chromium・Safari・Firefox のすべてで動く。

2. Switch：押している間、つまみが伸びる

今
つまみが滑って、トラックの色が変わる。
候補
押している間だけ、つまみが横に少し伸びる。指を離すと、伸びたまま滑ってから元の形に戻る。
ブラウザ
すべてのブラウザで動く。マウスやタッチで押している間だけ伸びる（キーボードでは伸びない）。

3. Radio：点が弾んで現れる

今
中の点が、少し小さい状態から拡大して現れる。
候補
点が 0 から現れ、前の選択の点は縮んで消える。弾み方はパックのイージングに従う。Graphite はすっと止まり、Lucent は少し行き過ぎて戻る。
ブラウザ
すべてのブラウザで動く。

4. Tabs：選ばれたタブの下地が滑る

今
選ばれたタブの下地と文字の色が、その場で切り替わる。
候補
下地が、前のタブから新しいタブへ滑って移る。下地は 1 つの要素で、CSS のアンカー配置で選ばれたタブに重なる。部品に下地用の要素を 1 つ足す変更になる（このページでは、置き換えたあとの列にだけ足している）。
ブラウザ
Chromium と Safari は滑る。Firefox は滑らずに切り替わる（今と同じ見た目）。

5. Toast：消えたあと、残りが滑って詰まる

今
消えるトーストはフェードし、消えた瞬間に残りが詰まる。
候補
消えるトーストが横に抜けながら高さを畳み、残りが滑って詰まる。
ブラウザ
高さの畳み込みは Chromium だけ（interpolate-size）。Safari と Firefox は横に抜けて消え、残りが詰まる動きは今と同じ。

6. Button：処理中のスピナーをフェードで出す

今
処理中になると、スピナーがいきなり現れる。
候補
スピナーが、小さい状態からフェードしながら現れる（@starting-style）。
ブラウザ
すべてのブラウザで動く。ボタンの幅は、今と同じく一瞬で変わる。

おまけ. Accordion：中身をフェードさせる

今
Chromium は高さが滑らかに開く。Firefox と Safari は、一瞬で開く。
候補
高さの動きに、中身のフェードを足す。Safari では、高さは動かないが、フェードは付く。
ブラウザ
フェードは Chromium と Safari。Firefox は今と同じく一瞬で開く。高さは Chromium だけ（今と同じ）。
