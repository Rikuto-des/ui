動きはブラウザに、見た目はパックに。

ダイアログもポップオーバーも、ブラウザが持っている仕組みで動く React の UI ライブラリです。JavaScript はほとんど要りません。見た目はパックで丸ごと着せ替えられ、AI に書かせても崩れません。

  • 告知メールの文面を確定する10/24対応中
  • SNS 広告を入稿する10/21期限切れ
  • 申し込みページの画像を差し替える10/25未着手

このパネルの開閉はどれも JavaScript を使っていません。スクリプトが 0 個の版でも同じように動きます。

ダイアログとポップオーバーで 1 KB

開閉、フォーカスの閉じ込め、重なり順、位置合わせをブラウザに任せているので、同じ部品を数十分の一のコードで実装できます。表示が速く、Server Components のまま使え、JavaScript を読み込む前から動きます。

Dialog と Popover、minify と gzip 後、React 本体を除く。2026 年 10 月 22 日に同じ条件で実測。

同じコードのまま、ブランドごと着せ替える

見た目はコードに焼き付けず、パックが当てます。属性を 1 つ変えるだけで、アプリ全体でも一部分だけでも切り替わります。顧客ごとにブランドが違う SaaS や、別の見た目の埋め込みウィジェットに向いています。

<!-- 違うのはこの属性だけ -->
<section data-pack="graphite">…</section>
<section data-pack="lucent">…</section>

AI に書かせても、デザインが崩れない

部品ごとの契約から、型・lint・AI 向けの説明書を自動で作ります。色や角を直接書くとエラーになり、エラー文が直し方を伝えます。エージェントはそれを読んで、自分で直します。

// エージェントが書いたコード
<Button className="bg-red-500 rounded-xl px-6">
  削除
</Button>
urushi/no-visual-overrideButton の色・角・余白は className では変えられません。代わりに variant="danger" を使ってください。角と余白はパックが決めます。

コピーして所有しても、更新を受け取れる

手元にコピーされるのは薄いファイルだけ。入れたときの版とハッシュを記録しているので、自分で変えた箇所を残したまま新しい版を取り込めます。

diff は実装済み、update は次の段階で実装します。

$ urushi diff
変更なし  components/ui/button.tsx
変更あり  components/ui/dialog.tsx

$ urushi update dialog
dialog 0.1.0 → 0.2.0
あなたの変更を残して更新しました

日本語が、最初から綺麗に組まれる

約物の詰め、禁則、文節での改行、和文と英数字のあいだの空き、日本語に合った行間を標準にしています。英語を前提にしたライブラリでは、ここを毎回自分で整える必要があります。
