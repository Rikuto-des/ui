部品

21 種類。どれも Server Components のまま描画でき、多くはブラウザ標準の要素だけで動きます。上のバーでパックとテーマを切り替えると、同じ部品がそのまま着せ替わります。

Button

押すと何かが起きる操作。ページ内で一番大事な操作にだけ primary を使います。

土台
<button>
JavaScript
不要

Link

別のページや場所への移動。操作には Button を使います。

土台
<a>
JavaScript
不要

Menu

ボタンから開く操作の一覧。開くと最初の項目にフォーカスが移り、矢印キーで選べます。

土台
popover="auto"
JavaScript
矢印キーとタイプアヘッドだけ

Field + Input

ラベル・説明・エラーを入力欄に結びつけます。結びつけは Field が行うので、書き忘れがありません。

土台
<label> と aria-describedby
JavaScript
不要

Textarea

複数行の入力。対応ブラウザでは入力に合わせて高さが伸びます（スクリプトなし）。

土台
field-sizing: content
JavaScript
不要

Select

決まった選択肢から 1 つ選ぶ。base-select に対応したブラウザでは、開いた一覧もパックの見た目になります。

土台
<select> と base-select
JavaScript
不要

Checkbox

オン・オフを個別に選ぶ。ラベル全体が押せる範囲です。

土台
<input type="checkbox">
JavaScript
不要

Switch

押した瞬間に反映される設定。保存ボタンが必要なら Checkbox を使います。

土台
role="switch"
JavaScript
不要

RadioGroup

いくつかの中から 1 つ選ぶ。グループ内は矢印キーで移動します（ブラウザ標準の動き）。

土台
<fieldset> と radio
JavaScript
不要

Card

まとまった内容の入れ物。見出しレベルを指定して、ページの見出し構造を崩さないようにします。

土台
見出しレベルを選べる
JavaScript
不要

Badge

状態や件数を短く示すラベル。色だけに頼らず、言葉で伝えます。

土台
<span>
JavaScript
不要

Tabs

同じ場所で内容を切り替える。選ばれたタブはサーバーで決まり、切り替えと矢印キーはランタイムが担います。

土台
ARIA tabs をサーバーで描画
JavaScript
切り替えに必要

Accordion

見出しを押すと中身が開く。name を渡すと、1 つ開くとほかが閉じます。

土台
<details name>
JavaScript
不要

Separator

内容の区切り。飾りだけのときは decorative にして、読み上げから外します。

土台
<hr>
JavaScript
不要

Skeleton

読み込み中の場所取り。読み上げからは外れるので、状態は Spinner などで伝えます。

土台
CSS のみ
JavaScript
不要

Spinner

処理中であることを示す。読み上げでは label の文言が伝わります。

土台
role="status"
JavaScript
不要

Dialog

作業を止めて確認や入力を求める。開いている間、背景は操作もスクロールもできません。

土台
<dialog> と command
JavaScript
不要

Popover

ボタンの近くに出る小さなパネル。外側を押すか Esc で閉じます。

土台
popover とアンカー配置
JavaScript
不要

Tooltip

ボタンの補足。ホバーかキーボードのフォーカスで出ます。名前の代わりにはせず、アイコンだけのボタンには aria-label を付けます。

土台
popover="hint" と interestfor
JavaScript
Chromium 以外で必要

Toast

操作の結果を短く知らせる。読み上げにも伝わり、開いているダイアログより手前に出ます。

土台
popover="manual" と aria-live
JavaScript
表示に必要
