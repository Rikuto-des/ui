コンポーネント

49 種類。どれも Server Components のまま描画でき、多くはブラウザ標準の要素だけで動きます。上のバーでパックとテーマを切り替えると、同じコンポーネントがそのまま着せ替わります。

Button

押すと何かが起きる操作。ページ内で一番大事な操作にだけ primary を使います。

土台
<button>
JavaScript
不要

Link

別のページや場所への移動。操作には Button を使います。

土台
<a>
JavaScript
不要

ButtonGroup

まとまりのある操作を 1 つの形につなげます。いくつかから 1 つを選ぶなら ToggleGroup を使います。

土台
role="group"
JavaScript
不要

Toggle

押すと入り、もう一度押すと切れる。中身はチェックボックスなので、フォームで送られます。

土台
<input type="checkbox">
JavaScript
不要

ToggleGroup

ひと続きのボタンの形をした選択肢。1 つ選ぶならラジオ、いくつも選ぶならチェックボックスです。

土台
radio と checkbox
JavaScript
不要

Menu

ボタンから開く操作の一覧。開くと最初の項目にフォーカスが移り、矢印キーで選べます。

土台
popover="auto"
JavaScript
矢印キーとタイプアヘッドだけ

ContextMenu

右クリック・長押し・Shift+F10 で、押した場所に出る操作の一覧。中身は Menu と同じで、同じ操作はほかの方法でもできるようにします。

土台
popover="auto"
JavaScript
右クリックで開くのに必要

Menubar

アプリの上に並ぶメニュー（ファイル・編集・表示）。左右の矢印でメニューを移り、開いたまま隣に動くと切り替わります。

土台
role="menubar" と popover="auto"
JavaScript
矢印キーとホバーでの切り替えだけ

Field + Input

ラベル・説明・エラーを入力欄に結びつけます。結びつけは Field が行うので、書き忘れがありません。

土台
<label> と aria-describedby
JavaScript
不要

InputGroup

入力欄の前後に決まった文字やボタンをつなげます。Field の中に置けば、ラベルや説明は中の Input に結びつきます。

土台
:has() で 1 つの枠に
JavaScript
不要

Textarea

複数行の入力。対応ブラウザでは入力に合わせて高さが伸びます（スクリプトなし）。

土台
field-sizing: content
JavaScript
不要

Select

決まった選択肢から 1 つ選ぶ。base-select に対応したブラウザでは、開いた一覧もパックの見た目になります。

土台
<select> と base-select
JavaScript
不要

Checkbox

オン・オフを個別に選ぶ。ラベル全体が押せる範囲です。

土台
<input type="checkbox">
JavaScript
不要

Switch

押した瞬間に反映される設定。保存ボタンが必要なら Checkbox を使います。

土台
role="switch"
JavaScript
不要

RadioGroup

いくつかの中から 1 つ選ぶ。グループ内は矢印キーで移動します（ブラウザ標準の動き）。

土台
<fieldset> と radio
JavaScript
不要

Slider

だいたいの量を選ぶ。正確な数が大事なら Input を使います。

土台
<input type="range">
JavaScript
不要

DateInput

日付や時刻。ブラウザ自身のピッカーが開き、表示の形は利用者の言語設定に従います。

土台
<input type="date">
JavaScript
不要

FileInput

ファイルの添付。dropzone はファイルを落とせる大きな的になります（スクリプトなし）。

土台
<input type="file">
JavaScript
不要

OTPInput

ワンタイムコード。1 つの入力欄を桁ごとの枠に描くので、貼り付けや読み上げはふつうの入力欄と同じです。

土台
one-time-code
JavaScript
不要

Card

まとまった内容の入れ物。見出しレベルを指定して、ページの見出し構造を崩さないようにします。

土台
見出しレベルを選べる
JavaScript
不要

Badge

状態や件数を短く示すラベル。色だけに頼らず、言葉で伝えます。

土台
<span>
JavaScript
不要

Avatar

人を示す写真。写真がないときや読み込めないときは、名前の頭文字を出します。

土台
role="img" と <img>
JavaScript
不要

Kbd

キーやショートカット。組み合わせは Kbd を並べます。

土台
<kbd>
JavaScript
不要

Table

同じ列で項目を比べる。caption が表の名前になり、幅が足りないときは表だけが横にスクロールします。

土台
<table> と <caption>
JavaScript
不要

Tabs

同じ場所で内容を切り替える。選ばれたタブはサーバーで決まり、切り替えと矢印キーはランタイムが担います。

土台
ARIA tabs をサーバーで描画
JavaScript
切り替えに必要

Accordion

見出しを押すと中身が開く。name を渡すと、1 つ開くとほかが閉じます。

土台
<details name>
JavaScript
不要

Collapsible

1 つの区画を開け閉めする details。区画がいくつも並ぶなら Accordion を使います。

土台
<details>
JavaScript
不要

Separator

内容の区切り。飾りだけのときは decorative にして、読み上げから外します。

土台
<hr>
JavaScript
不要

AspectRatio

縦横比を保つ箱。中の画像や動画は箱いっぱいに広がります。

土台
aspect-ratio
JavaScript
不要

ScrollArea

名前の付いたスクロール領域。フォーカスできるので、キーボードでもスクロールできます。

土台
role="region"
JavaScript
不要

Carousel

横にスクロールして順に見せるスライド。勝手には動かず、対応ブラウザでは前後のボタンと点をブラウザが足します。

土台
::scroll-marker
JavaScript
不要

Alert

ページに置いておく知らせ。見出しで言い切り、トーンの色とアイコンは補うだけです。

土台
見出しのある面
JavaScript
不要

Progress

作業がどこまで進んだか。合計がまだわからない間は value を省くと、流れる表示になります。

土台
<progress>
JavaScript
不要

Meter

決まった範囲の中の量。optimum からどれだけ離れているかで、ブラウザが色を決めます。

土台
<meter>
JavaScript
不要

Spinner

処理中であることを示す。読み上げでは label の文言が伝わります。

土台
role="status"
JavaScript
不要

Skeleton

読み込み中の場所取り。読み上げからは外れるので、状態は Spinner などで伝えます。

土台
CSS のみ
JavaScript
不要

Empty

一覧にまだ何もないとき。何が空で、どう始めればよいかを示します。

土台
CSS のみ
JavaScript
不要

Breadcrumb

今のページがサイトのどこにあるか。区切りの印は CSS で描き、読み上げません。

土台
<nav> と <ol>
JavaScript
不要

Pagination

長い一覧のページ送り。すべてふつうのリンクで、href は URL の型から作ります。

土台
<nav> とリンク
JavaScript
不要

Steps

決まった手順のどこにいるか。今の手順に aria-current が付き、状態は言葉でも読み上げます。

土台
aria-current="step"
JavaScript
不要

Sidebar

アプリの主なナビゲーション。グループは details で畳めます（スクリプトなし）。

土台
<nav> と <details>
JavaScript
不要

Dialog

作業を止めて確認や入力を求める。開いている間、背景は操作もスクロールもできません。

土台
<dialog> と command
JavaScript
不要

AlertDialog

取り消せない操作の確認。Esc でも外側でも閉じず、最初のフォーカスはキャンセルに置かれます。

土台
role="alertdialog"
JavaScript
不要

Sheet

画面の端から滑り出るダイアログ。左右は書字方向に従います。

土台
<dialog> と command
JavaScript
不要

Popover

ボタンの近くに出る小さなパネル。外側を押すか Esc で閉じます。

土台
popover とアンカー配置
JavaScript
不要

HoverCard

リンクの先をのぞき見るカード。ホバーかキーボードのフォーカスで出て、ポインタをカードに移しても消えません。

土台
popover と interestfor
JavaScript
Chromium 以外で必要

Tooltip

ボタンの補足。ホバーかキーボードのフォーカスで出ます。名前の代わりにはせず、アイコンだけのボタンには aria-label を付けます。

土台
popover="hint" と interestfor
JavaScript
Chromium 以外で必要

Toast

操作の結果を短く知らせる。読み上げにも伝わり、開いているダイアログより手前に出ます。

土台
popover="manual" と aria-live
JavaScript
表示に必要
