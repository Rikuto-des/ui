# AI に画面を作らせる課題

`scripts/ai-lint-rate.ts` が使う課題。1 ファイルが 1 課題で、`NN-名前.md` の 1 行目（`# …`）が課題名、残りがそのまま Claude に渡す依頼文になる。

依頼文は、利用者がコーディングエージェントに頼むときの書き方にする。

- どの部品を使うかは書かない（「Field で包んで」などは書かない）。部品を選ぶところから測るため。
- 見た目の指定（「赤で目立たせて」「影を強めに」「幅は 400px くらい」）は、実際の依頼でよく出るので、いくつかの課題に入れている。正しくはバリアントやトークンで表すもので、ここで崩れるかどうかを見る。

課題を足したら `node scripts/ai-lint-rate.ts --dry-run` で読み込めるか確かめる。結果は [docs/phase1/ai-lint-rate.md](../../docs/phase1/ai-lint-rate.md)。
