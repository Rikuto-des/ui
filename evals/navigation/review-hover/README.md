# Navigation Menu：ホバーと横開きの最終レビュー

2026年10月28日。`packages/core/src/navigation-menu.ts`、部品のCSS、契約、型、使用例を更新した。

## 実装した動作

- マウスのホバーで開き、兄弟の項目へ短い待ち時間で切り替える。最初は180ms、切替は70ms、入れ子は160ms。ホバーだけでフォーカスは移さない。
- パネルとの隙間には閉じるまで300msの猶予を設けた。入れ子へ斜めに向かう間は三角形の領域で移動方向を判定し、最大700msまで親子のパネルを維持する。
- 入れ子は横へ開く。画面端では反転し、横の空きが足りなければ縦へ戻す。上下の位置、スクロール、サイズ変更にも追従する。トリガーが画面外に出たら閉じる。
- Popover APIのトップレイヤーを使い、親要素のoverflowによる切れを防ぐ。DOMは移動しない。Tabの順序、通常のリンク、JavaScriptなしの開閉を保つ。
- ホバーで開いた後の最初のクリックは開いたままにする。次のクリックで閉じる。Escape、外側クリック、フォーカス移動でも閉じる。キーボードで操作中のパネルをマウス移動で隠さない。
- 子へ進む右矢印、親へ戻る左矢印に対応し、RTLでは方向を反転する。タッチは明示的な操作で開く。狭い画面では縦に展開する。
- `openOnHover={false}`、`submenu="inline"`で操作を選べる。Popover APIがない場合も縦展開で使える。
- 見出し、矢印、現在地、影、余白、説明文の階層を調整。動きを減らす設定ではパネルのアニメーションとリンクの遷移を止める。
