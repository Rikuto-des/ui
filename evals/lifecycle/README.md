## 何を揃えたか

削除確認、タブ、行メニューの3課題を各2試行。前回の `measured-v4` の最終更新出力を全件使い、不合格だった出力も除外していません。TSXのハッシュ、shadcnのコピー済み部品、Urushiの実装、共通CSS、型設定、4つの操作検査を更新前後で揃えています。

| 対象 | 更新前 | 更新後 |
| --- | --- | --- |
| React / React DOM・全ライブラリ共通 | 19.3.0 | 19.3.1 |
| Base UI | 1.8.0 | 1.9.0 |
| Radix UI | 1.7.0 | 1.8.1 |
| shadcn/uiのRadix依存 | 1.7.0 | 1.8.1 |

それぞれ `environments/before` と `environments/after` に実際にインストールしました。直接依存は完全なバージョン番号で固定し、間接依存は各ロックファイルで固定しています。実際に解決したパッケージのバージョンとロックファイルのハッシュも保存しました。CSSの解析にPostCSS 8.5.32を使っています。

Urushiは公開前の0.0.0です。Urushi自身のリリース移行を行った実験ではありません。shadcnのレジストリソース更新も対象外です。新しいAPI向けに生成したコードを旧版で再生してから比較しているため、長期運用中のアプリの移行とは異なります。

## サイズ

各ファイルをminifyしてからgzipしたバイト数を足しています。React、React DOM、部品CSS、パックCSS、共通の評価用CSSを含みます。画像、フォント、HTMLは含みません。共通CSSは前回のファイルをそのままコピーし、内容スキャンの対象が増えてサイズが変わらないようにしました。

現在のUrushiは別の `release-v2` で測定しています。Navigation MenuとSafariのDialogフォーカス補助を含むランタイムを使用します。前回の生成TSXは変更せず、使用する部品のCSSを選択しました。公開トークンはすべて残しています。

この方法は共通条件で差を比べるためのものです。各ライブラリに最適化した独立のTailwindビルド、アプリの画像やフォント、配信速度、CPU時間は比較していません。

## 表示と操作

- 共通の依存更新検査：54画面×4検査。212通過、4不合格。不合格はBase UIのタブ2件が更新前後で同じ条件に合わなかったものです。新しい失敗はありません。
- 現在のUrushi：6画面×4検査×3ブラウザーで72件通過。
- CSS分割：47部品のサイト使用例を2パック×2テーマ×2幅で376件照合。各条件で通常状態と開いた状態を比較しました。Toastは命令的に生成するため、このSSR照合から除外し、既存のランタイムE2Eで確認しています。
- CSS照合では、表示される要素の座標、配色、文字、枠、疑似要素、動きの定義を一致させます。画像の文字描画には微差があったため、RGBの差4/255を超える画素が最大16個までという許容値を設けています。レイアウトや計算済みCSSには許容値を設けていません。
- Navigation Menu：入れ子、Escape、外側クリック、通常のTab移動、RTL、320px、4配色、JavaScript無効時を3ブラウザーで確認。macOS WebKitの通常設定ではネイティブリンクへの移動にOption+Tabを使います。
- 実画面も確認しました。デスクトップのパネル内リンク名がネイティブのアクセシビリティツリーへ出ない問題を見つけ、開いた `::details-content` の構造を修正しました。スクリーンリーダーを使った操作検証とは区別しています。

## 修正した弱点

1. 全CSSの一括読み込み。部品ごとのCSSエクスポートと `urushi css` を追加し、内部で使う部品のスタイルも契約から辿るようにしました。
2. 分割時の共通アクセシビリティ規則。読み上げ用テキストが画面に出る問題を画像照合で検出し、非表示規則を常に保持するようにしました。
3. SafariでマウスからDialogを開いた場合のフォーカス復帰。ネイティブの開く処理の前に起点をフォーカスし、閉じたときに戻れるようにしました。アプリが開く操作を取り消した場合はフォーカスを変更しません。
4. Navigation Menuの欠落。リンクと入れ子の開閉を専用部品として追加し、API・型・lint・配布データ・使用例を揃えました。
5. Lucentライトでのコードコメントのコントラスト。サイトの構文色を調整しました。

## 校正履歴

`dependency-v1` は測定器の校正記録です。Base UIを絶対ディレクトリへaliasしたため、正式なESMエクスポートを通らずCommonJSを選び、サイズを過大評価していました。最終の `dependency-v2` はパッケージの正式なexportsを通します。Base UIの新版バンドルサイズが前回のESM測定と一致することも確認しました。共通の合否検査は変更していません。

画像比較では、読み込み完了、描画完了、有限アニメーションの終了を待つようにしました。無限アニメーションは同じ時刻で停止させ、テーマは初回描画前に揃えています。別のPlaywright実行が出力フォルダを削除する競合もあったため、最終確認は順番に実行しています。

`release-v1` ではSafariのDialogのフォーカス復帰に2件失敗しました。実装を修正した `release-v2` は72件通過しました。前回の競合実験の保存済みコード・採点は書き換えていません。
