# 日本語組版

英語を前提にしたライブラリでは、日本語の組版を毎回自分で整える必要があります。yourlib では、次の設定をパックの標準にしています。

| 設定 | 何をするか | 対応 |
|---|---|---|
| `line-break: strict` | 句読点や小書きの仮名が行頭に来ないようにする（禁則） | 全ブラウザ |
| `text-autospace: normal` | 和文と英数字のあいだに、自動で少し空きを入れる | 全ブラウザ |
| `font-feature-settings: "palt"` | 見出しの約物を詰める | 全ブラウザ |
| `word-break: auto-phrase` | 見出しを文節の途中で改行しない | Chromium（他のブラウザでは通常の改行） |
| `text-wrap: balance` / `pretty` | 見出しの行の長さをそろえ、本文の最終行が 1 文字だけになるのを避ける | 全ブラウザ |
| 行間 1.75（本文）、1.5（見出し） | 日本語に合わせた行送り | — |

## 決まり

- 本文には palt を付けません。字間が詰まりすぎて読みにくくなるためです。
- 本文の字間は 0.01em です。手で `letter-spacing` を広げないでください。
- 和文と英数字のあいだに、手でスペースを入れる必要はありません。
- 数字が縦に並ぶ場所は `tabular-nums` で桁をそろえます。
- 縦書きとルビは、今のところ扱っていません。
