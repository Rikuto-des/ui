AlertDialogは取り消せない操作の前に確認を求めるモーダルダイアログです。`role="alertdialog"`を指定しています。ボタンでしか閉じません。

## 使う場面

- 削除など、取り消せない操作を確認するときに使います。

## 使わない場面

- フォームや長めの作業には Dialog を使います。

## 必要な設定

- `id`：`AlertDialog.Trigger`・`Cancel`・`Action` がこの id を参照します。
- `title`：必須です。問いの形にします（「「秋のキャンペーン」を削除しますか？」）。
- `description`：必須です。何が起きるかを具体的に書きます。
- childrenには`AlertDialog.Cancel`と`AlertDialog.Action`を置きます。

## 振る舞い

- Esc キーや外側のクリックでは閉じません。
- 開くとフォーカスはキャンセルに置かれ、閉じると開いたボタンに戻ります。
- Action は既定で danger の見た目で、押すとダイアログを閉じます。実際の処理は `onClick` か、フォームの送信で行います。
- ここまで JavaScript なしで動きます。

## 実装時の注意

- 「よろしいですか？」だけで終わらせないでください。何が消えるかを書きます。
- Actionの文言を「OK」にしないでください。「削除する」のように、起きることを書きます。

## 操作例と追加設定

操作例ではアーカイブ前の確認と操作後の復元を試せます。開いたときは安全な選択肢にフォーカスし、Escapeで意図せず確定することはありません。
