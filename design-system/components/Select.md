Select は、決まった選択肢から 1 つを選ぶネイティブの `<select>` です。

## 使う場面

- 選択肢が 5 つ以上ある、または画面の場所が限られているとき。

## 使わない場面

- 選択肢が 2〜4 つで、全部を見せて比べてほしいときは RadioGroup を使います。
- 操作の一覧には Menu を使います。

## 利用者が用意するもの

- Field の中に置きます。
- children に `<option>`。
- `placeholder`：何も選ばれていない状態の文言です。選べない先頭の選択肢になります。

## 振る舞い

- `appearance: base-select` に対応したブラウザ（Chromium・Safari）では、開いた一覧もパックの見た目になります。それ以外のブラウザでは、ボタンはパックの見た目、一覧は OS の標準になります。
- キーボード操作・検索・フォーム送信は、ブラウザ標準のままです。

## してはいけないこと

- `<div>` と JavaScript で独自の選択欄を作らない。ネイティブの select で足りない場合は、まず Menu か RadioGroup で済まないか考えます。
