Tabs は、同じ場所で内容を切り替える、ARIA のタブです。選ばれたタブはサーバーで決まり、切り替えは任意のランタイムが担います。

## 使う場面

- 同じものの別の見方（概要・タスク・メンバー）を、行き来しながら見るとき。

## 使わない場面

- 順に進む手順には使いません。
- 内容を同時に比べるなら、並べて見せます。
- 別のページへの移動はリンクのナビゲーションにします。

## 利用者が用意するもの

- Tabs に `id`・`label`（タブの一覧の名前）・`defaultValue`。
- `Tabs.List` の中に `Tabs.Tab`（`value` と文言）、Tabs の直下に同じ `value` の `Tabs.Panel`。
- `value` が食い違っていると表示されないパネルができるので、lint（`yourlib/tabs-match`）が知らせます。

## 振る舞い

- クリックで切り替わります。矢印キーで隣のタブへ移って選び、Home と End で端へ移ります。縦向き（`orientation="vertical"`）では上下の矢印です。
- Tab キーで、選ばれたタブからパネルへ移ります。
- JavaScript がないと切り替えはできず、`defaultValue` のパネルだけが見えます。
- 選ばれたタブの下地は 1 つの要素で、CSS のアンカー配置で選んだタブに重なり、選択が移ると滑って移ります（Chromium・Safari）。Firefox と、動きを減らす設定では、滑らずに切り替わります。下地は読み上げから外れています。

## してはいけないこと

- タブの中にタブを入れない。
- タブの文言を長くしない。1〜2 語にします。
