NavigationMenuはWebサイトのヘッダーで階層ごとにリンクをまとめます。グループを開いてページを選べます。入れ子のグループにも対応します。

## 使う場面

- 製品や開発者向け資料、会社情報などをまとめたサイトのナビゲーションに使います。
- JavaScriptの読み込み前からリンクや開閉を使えるようにしたい場合に向いています。

## 使わない場面

- 編集や削除などの操作には Menu を使います。
- アプリの左側に常時表示するナビゲーションには Sidebar を使います。

## 必要な設定

- `NavigationMenu`にはナビゲーションを区別する`label`を指定します。
- `NavigationMenu.Group`には文字列の`title`を指定します。中には Link または別の Group を置きます。
- `NavigationMenu.Link`には`href`を指定します。今のページだけに `current` を付けます。
- リンクには補足の `description` も付けられます。
- リンクが多いグループは `columns={2}` で2列にできます。狭い画面では自動で1列に戻ります。
- クリックとキーボードだけで開く場合は、ルートに `openOnHover={false}` を指定します。入れ子を常に縦展開する場合は、グループに `submenu="inline"` を指定します。

## 振る舞い

- 開閉にはネイティブの `<details>`、移動には通常のリンクを使います。クリック、Enter、Space、Tabで操作できます。
- 幅641px以上でマウスを使う場合は、少し待ってからホバーで開きます。項目の切替は短い待ち時間にし、パネルとの隙間や斜め移動で閉じにくくしています。ホバーだけでフォーカスは移しません。
- ホバーで開いた直後のクリックは、開いた状態を保ちます。もう一度クリックすると閉じます。タッチでは明示的な操作で開きます。狭い画面ではホバーを使わず、内容を縦に並べます。
- `UrushiRuntime` があると、同じ階層では1グループだけ開きます。Escapeで直近のグループを閉じて見出しに戻り、外側クリックやフォーカスの移動でも閉じます。
- ランタイムの矢印キー操作では、見出しから下・上で先頭・末尾に移れます。入れ子では右で子へ入り、左で親へ戻ります。RTLでは左右を反転します。Tabの通常の順番は保ちます。
- 横に開くパネルは画面端で左右を反転し、上下の空きにも合わせます。横幅が足りない場合は縦展開に戻ります。スクロールやウィンドウのサイズ変更にも追従します。
- 同じ階層のパネルを切り替えると、背景の位置・幅・高さが240msで連続的に変わります。文字は拡大縮小せず、内容だけを短くフェードさせます。途中で別の項目へ移っても、その時点の形から次へつながります。
- 上位のグループを開いた状態では、左右キーで隣の見出しへ移るとパネルも切り替わります。閉じた状態ではフォーカスだけが移ります。
- パネルにはPopover APIのトップレイヤーを使い、親の `overflow: hidden` で切れないようにしています。DOMを別の場所に移さず、リンクの順序を保ちます。ランタイムやPopover APIがない場合、入れ子は縦展開で使えます。
- Escapeはホバーで開いたパネルも閉じます。キーボードでパネル内を操作している間は、マウスが外れても閉じません。動きを減らす設定では、開くときのアニメーションを止めます。
- 背景の面は装飾用で、読み上げやTabの対象になりません。リンクを複製したり、DOM上の場所を移したりしません。動きを減らす設定に途中で切り替えた場合も、変形と内容のアニメーションを止めます。

## CSSを必要な分だけ読み込む

```tsx
import "@urushi/packs/graphite.css";
import "@urushi/react/styles/navigation-menu.css";
```

全コンポーネント用の `styles.css` も引き続き使えます。複数コンポーネントのCSSを一つにまとめる場合は `urushi css navigation-menu button` の出力を保存して読み込みます。パックのCSSは別途必要です。

## 実装時の注意

- サイト内のリンクに`role="menu"`や`role="menuitem"`を付けないでください。
- 見出しにリンクやボタンを入れないでください。
- 同じナビゲーションで複数のリンクに`current`を付けないでください。
