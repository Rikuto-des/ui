Tableはパックの見た目を当てたネイティブの `<table>` です。`thead`・`tbody`・`th`・`td` はいつもどおり書きます。

## 使う場面

- 同じ列で項目を比べるときに使います。
- 行ごとに属性がいくつもある一覧に使います。

## 使わない場面

- ページのレイアウトには CSS grid を使います。

## 必要な設定

- `caption`：必須です。表の名前として読み上げられます。見た目で要らなければ `hideCaption` で隠します。
- `density`は`default`（既定）か`compact`を選びます。
- `striped`：1 行おきに面の色を付けます。
- children：見出しのセルは `<th scope="col">`、行の見出しは `<th scope="row">` にします。

## 振る舞い

- 幅が足りないときは、表だけが横にスクロールし、ページ全体ははみ出しません。

## 実装時の注意

- `caption`を省かないでください。
- ページのレイアウトのために使わないでください。

## 操作例と追加設定

操作例では金額の加算と行の密度を切り替えられます。数値は桁幅を揃えて右寄せし、合計をtfootに置いています。
