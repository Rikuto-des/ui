Dialog は、作業を中断して確認や短い入力を求める、モーダルなネイティブの `<dialog>` です。

## 使う場面

- 削除など、取り消せない操作の確認。
- 先に進む前に終わらせる必要がある、短い入力。

## 使わない場面

- 操作の横に補足を出すだけなら Popover を使います。
- 操作の結果を知らせるだけなら、トースト（Toaster と toast()）を使います。

## 利用者が用意するもの

- `id`：`Dialog.Trigger` と `Dialog.Close` がこの id を参照します。
- `title`：必須です。見出しになり、ダイアログの名前として読み上げられます。確認ダイアログでは問いの形にします。
- `description`：任意です。何が起きるかを具体的に書きます。
- children：本文やフォームと、最後に `Dialog.Actions`（主な操作を右端に置きます）。

## 振る舞い

- 開くと背景は操作できなくなり、ページのスクロールも止まります。フォーカスは中に閉じ込められ、閉じると開いたボタンに戻ります。
- `dismissible="any"`（既定）：Esc キーと外側のクリックで閉じます。`"closerequest"`：Esc キーだけ。`"none"`：明示的なボタンでしか閉じません（入力途中のフォームに使います）。
- `<form method="dialog">` の中で送信すると、ダイアログが閉じます。
- ここまですべて JavaScript なしで動きます。

## してはいけないこと

- ダイアログの中で、さらにダイアログを開かない。
- 危険な確認ダイアログでは、危険な側のボタンに `autoFocus` を付けない。キャンセルに付けます。
