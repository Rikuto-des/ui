Sliderはネイティブの範囲入力です。つまみに追従する値の表示や、直接選べる目盛りを追加できます。

## 使う場面

- 音量や明るさなど、正確な数よりおおよその量を調整したい場合に使います。

## 使わない場面

- 正確な数を入れるなら Input を使います。

## 必要な設定

- Fieldの中に置いてラベルを付けます。
- `min`・`max`・`step`・`defaultValue`：ネイティブのままです。

## 振る舞い

- 矢印キーで 1 目盛り、Page Up / Page Down で大きく、Home / End で端まで動きます。

## 値を見ながら調整する

`showValue`で現在の値をつまみの上に表示し、`valueSuffix="%"`などで単位を添えられます。読み上げに独自の単位が必要なら、`aria-valuetext`にも指定します。

`marks={[{ value: 0, label: "小さく" }, { value: 100, label: "大きく" }]}`で目盛りを置けます。目盛りを押すと値が変わり、Reactの`onChange`にも反映されます。目盛りのラベルは短く、数を絞ってください。

追従表示と目盛りからの選択には`UrushiRuntime`が必要です。JavaScriptなしでも範囲入力は操作できます。その場合、追従表示は隠し、目盛りは値を変えない表示になります。

## 実装時の注意

- 値そのものが大事な場合は、現在の値を表示してください。
