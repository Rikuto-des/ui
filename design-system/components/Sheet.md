Sheetは画面の端からスライドして開くモーダルな`<dialog>`です。

## 使う場面

- 一覧の横で詳細やフォームを開くときに使います。
- 小さな画面のナビゲーションや絞り込みに使います。

## 使わない場面

- 短い確認には AlertDialog を使います。

## 必要な設定

- `id`：`Sheet.Trigger` と `Sheet.Close` がこの id を参照します。
- `title`：必須です。見出しになり、名前として読み上げられます。
- `description`：任意の補足です。
- `side`：表示する端を`end`（既定）・`start`・`top`・`bottom`から選びます。`start` と `end` は書字方向に従います。
- `size`は`sm`・`md`（既定）・`lg`から選びます。
- `dismissible`：Dialog と同じです。

## 振る舞い

- Dialog と同じく、背景は操作できなくなり、フォーカスは中に閉じ込められ、閉じると開いたボタンに戻ります。
- 開け閉めは端から滑ります。動きを減らす設定では、フェードだけになります。

## 実装時の注意

- Sheetの中でさらにSheetやダイアログを開かないでください。
- ページの主な内容をSheetの中に隠さないでください。

## 操作例と追加設定

操作例ではタイトルとグリッド表示を編集し、Sheet内で結果を確認できます。キャンセルでは変更を捨て、保存時に背面の表示へ反映します。
