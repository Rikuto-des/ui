Link は、別のページやページ内の場所へ移動するためのネイティブの `<a>` です。

## 使う場面

- 本文の中で、関連するページへ案内するとき（`variant="inline"`、既定）。
- 一覧の末尾の「すべて見る」のように、単独で置く移動先（`variant="standalone"`）。

## 使わない場面

- その場で何かを実行する操作には Button を使います。見た目がリンクでも、動作がボタンなら Button です。

## 利用者が用意するもの

- `href`：移動先です。
- children：移動先が分かる文言。「こちら」「詳しくは」だけにはしません。
- 別のサイトを新しいタブで開くときは `external`。`target="_blank"` と `rel="noopener noreferrer"` が付き、スクリーンリーダーには「新しいタブで開きます」と伝わります。

## 振る舞い

- Graphite では文字色のまま下線で示し、Lucent では action の色で示します（`--yl-color-link`）。
- `standalone` は下線を隠し、ホバーで下線を出します。

## してはいけないこと

- `className` で色を付けない。色はパックの `--yl-color-link` が決めます。
- `onClick` だけで動くリンクを作らない。移動しないなら Button です。
