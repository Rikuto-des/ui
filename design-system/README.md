yourlib は、ブラウザ標準の要素で動く React の UI ライブラリです。動きはブラウザに、見た目はパックに任せます。部品のコードは意味だけを持ち、色・形・密度・動きはパック（Graphite と Lucent）が決めます。このシステムで画面を作るときは、以下の決まりに従ってください。

## 原則

- **動きはブラウザに任せる。** ダイアログは `<dialog>` と `command="show-modal"`、ポップオーバーとメニューは `popover` 属性と CSS anchor positioning、アコーディオンは `<details name>`、ツールチップは `popover="hint"` と `interestfor` で開閉します。開閉のために状態管理や JavaScript を足さないでください。`Dialog.Trigger`・`Popover.Trigger`・`Menu.Trigger`・`Tooltip.Trigger` がその配線を持っています。
- **ランタイムは任意。** `<YourlibRuntime />` をルートに 1 つ置くと、メニューとタブのキーボード操作、Chromium 以外でのツールチップ、トーストが加わります。置かなくても、部品は表示され、開閉もできます。
- **最新の CSS で済むことに JavaScript を使わない。** 出入りのアニメーションは `@starting-style`、位置合わせは `position-area`、背景のスクロール止めは `:has(:modal)` です。
- **見た目はパックが決める。** 部品の色・角・余白・文字の大きさを `className` や `style` で上書きしないでください。上書きしてよいのは配置（外側の余白、幅、グリッド上の位置）だけです。別の見た目が必要なときは `variant` を使い、足りなければバリアントを追加します。
- **1 つの範囲には 1 つのパック。** ページ全体は `<html data-pack="graphite">` で決め、一部だけ変えるときは `data-pack="lucent"` を付けた要素で囲みます。1 つの部品の中でパックを混ぜないでください。
- **要素は id で結ぶ。** HTML の `<label for>` と同じように、`Dialog.Trigger dialog="id"` と `<Dialog id="id">`、`Popover.Trigger popover="id"` と `<Popover id="id">`、`Menu.Trigger menu="id"` と `<Menu id="id">`、`Tooltip.Trigger tooltip="id"` と `<Tooltip id="id">` を同じ id で結びます。入力欄のラベル・説明・エラーは `Field` が結びます。

## 文章の書き方

- 文体は「です・ます」。短い文で、主語と動作をはっきり書きます。
- ボタンには、押すと何が起きるかを動詞で書きます（「保存」「タスクを追加」「削除する」）。「OK」「はい」は使いません。同じ操作は流れの最後まで同じ言葉にします。
- 確認ダイアログの見出しは問いの形にします（「「秋のキャンペーン」を削除しますか？」）。説明文には、何が起きるかを具体的に書きます（「タスク 5 件とコメントがすべて消えます。」）。
- エラーは、何が起きたかと直し方を書きます。謝罪の言葉や曖昧な表現は入れません。
- 英数字は半角です。和文と英数字のあいだの空きは `text-autospace` が付けます。
- 絵文字や感嘆符で飾りません。

## 色

- 色はすべてトークンで指定します。生の色の値（`#fff` や `oklch()`）を直接書かないでください。
- 背景は `yl-color-bg`、面（パネルやカード）は `yl-color-surface`、オーバーレイ（ダイアログやポップオーバー）は `yl-color-surface-overlay` です。
- 本文は `yl-color-text`、補足は `yl-color-text-muted`、注記や日付は `yl-color-text-subtle` を使います。3 つとも、`yl-color-bg` と `yl-color-surface` の上で 4.5:1 以上のコントラストがあります。
- 主な操作は `yl-color-action` で、その上の文字は `yl-color-on-action` です。主ボタンは 1 つの画面に 1 つだけにします。
- `yl-color-accent` は、フォーカス・選択・進行中といった「状態」にだけ使います。装飾には使いません。
- `yl-color-danger` は、削除などの取り消せない操作と、期限切れの表示にだけ使います。
- Graphite は色をほぼ使わないパックです。主ボタンも墨色（`yl-color-action`）にし、色が出るのはフォーカス・選択・危険の 3 つだけにします。Lucent はラグーンの青緑 1 色を、主な操作とアクセントに使います。
- ダークモードは `data-theme="dark"` で切り替えます。何も指定しなければ OS の設定に従います。Graphite のダークモードでは、主ボタンが明るい色に反転します。

## 書体

- 書体は Noto Sans JP（`--font-sans`）だけを使います。ウェイトは 400（本文）、500（ボタン・ラベル）、700（見出し）の 3 つです。
- 本文の行間は 1.75、見出しは 1.5 前後にします。ページの大見出しは 1.22 まで詰めます。
- 見出しには約物を詰める指定（`font-feature-settings: "palt"`）を付け、`word-break: auto-phrase` で文節の途中では改行しないようにします。本文には palt を付けません。
- 数字が縦に並ぶ場所（期限、件数、金額）は `font-variant-numeric: tabular-nums` で桁をそろえます。
- 文字の大きさは書体スタイル（`display`、`heading`、`title`、`body`、`control`、`small`）から選び、その間の値は使いません。

## 余白とレイアウト

- 余白は `yl-space-1`〜`yl-space-6`（2・4・8・12・16・24px）の段階から選びます。部品どうしの間隔は `gap` で取り、個々の要素に margin を付けません。
- 文章は左揃えにします。1 行は全角 35〜40 字（約 32em）までにします。
- 区切りは線を足すより、まず余白で表します。線を使うときは `yl-color-border`（1px）にします。

## 角と形

- 角丸はパックごとに決まっています。Graphite は部品 8px、面 12px、ダイアログ 14px です。Lucent は部品 12px、面 22px、ダイアログ 28px で、対応ブラウザではスクワークル（`corner-shape: squircle`）になり、半径は 16・30・36px に広がります。
- 1 つの画面の中で、角丸の大きさを自分で変えないでください。

## 面と影

- Graphite の面は、不透明な紙として扱います。縁は `yl-shadow-panel` の 1px の輪で表し、オーバーレイだけに柔らかい落ち影（`yl-shadow-overlay`、`yl-shadow-dialog`）を付けます。すりガラスは使いません。
- Lucent の面は半透明の素材です。`yl-material-overlay`（ぼかし 28px）で背後の色を透かし、上辺の細いハイライトで縁を表します。透けて見えるものがない画面では、背景に淡い色面を敷いてください。
- 影の色やぼかしを、トークン以外の値で作らないでください。

## 動き

- 動きは、利用者の操作で何が変わったかを伝えるためにだけ使います。ページを開いたときの演出や、装飾的なループアニメーションは入れません。
- Graphite：通常は 120ms、オーバーレイは 140ms、イージングは `cubic-bezier(0.2, 0, 0, 1)`。現れるときは 0.98 倍から拡大し、弾みません。
- Lucent：通常は 160ms、オーバーレイは 260ms、イージングは `cubic-bezier(0.34, 1.3, 0.64, 1)`。わずかに弾み、0.95 倍から現れます。
- 「動きを減らす」設定（`prefers-reduced-motion: reduce`）では拡大縮小をなくし、フェードだけにします。パックが自動で切り替えます。
- 閉じるときのアニメーションは、`overlay` に対応したブラウザだけで動きます。対応していないブラウザでは即座に閉じます。
- 状態が変わるときの動きも、すべて CSS で付いています。チェックの印は左から右へ書くように現れ、ラジオの点は弾んで現れ、スイッチのつまみは押している間だけ伸びます。タブの下地は選んだタブへ滑り、消えるトーストは横に抜けて残りが詰まります。どれもパックのトークンの速さとイージングに従うので、Graphite はすっと止まり、Lucent は少し弾みます。
- 動きを減らす設定では、伸び縮み・滑り・畳み込みをすべて止め、フェードだけにします。
- 動きはブラウザの対応に合わせて段階的に付きます。タブの下地が滑るのは Chromium と Safari、トーストと Accordion の高さが動くのは Chromium です。対応していないブラウザでも、見た目と動作は崩れません。

## 状態

- ホバー：`yl-color-secondary-hover`、`yl-color-action-hover`、`yl-color-danger-hover`、`yl-color-ghost-hover`。
- 押下：パックの `press-scale` で、わずかに縮みます。
- フォーカス：`yl-color-focus-ring` の 2px の実線で、2px 離して表示します。すべての面に対して 3:1 以上のコントラストがあります。フォーカスの表示は消さないでください。
- 無効：不透明度 0.4。押せない理由が分かるときは、無効にするより理由を書いてください。
- 処理中：`loading` を指定するとスピナーが出て、`aria-disabled` になります。フォーカスは外れず、フォームの二重送信も防ぎます。

## アクセシビリティ

- ネイティブの要素がある場合は、それを使います（`<button>`、`<dialog>`、`<input type="checkbox">`）。`div` に `onClick` を付けて部品を作らないでください。
- ダイアログには必ず `title` を付けます。ポップオーバーには `title` か `aria-label` を付けます。
- 危険な操作の確認ダイアログでは、安全な側のボタン（キャンセル）に `autoFocus` を付けます。
- アイコンだけのボタンには `aria-label` を付けます。
- Safari では、マウスでクリックしてもボタンにフォーカスが移りません（Safari の標準動作）。キーボード操作でのフォーカスの戻り先は正しく動きます。

## アイコンとロゴ

- アイコンはライブラリに含めていません。必要なときは、部品の children に SVG を渡してください。線の太さと大きさは、ボタンの文字（`control` スタイル）にそろえます。
- 絵文字をアイコンの代わりに使わないでください。
- ロゴはまだありません。名前は書体（Noto Sans JP 700）で組みます。

## AI エージェントへ

- 画面を作る前に、どのパックと、どの部品の組み合わせを使うかを決めてください。
- 部品の props とバリアントは、各部品のページ（`components/<名前>/README.md`）にあります。そこに書かれていない props や値を作らないでください。
- 実際のプロジェクトでは `@yourlib/eslint-plugin` が、見た目の上書き・生の色の値・必須パーツの欠けをエラーにします。エラー文に代わりの書き方が書いてあるので、それに従って直してください。
