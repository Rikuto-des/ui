Urushiはブラウザ標準の要素で動くReactのUIライブラリです。コンポーネントで意味と構造を定義し、ブラウザの機能で動作させます。色や形、密度、アニメーションはGraphiteやLucentなどのパックで指定します。このシステムで画面を作るときは、以下の決まりに従ってください。

## 原則

- ブラウザ標準の機能を使います。ダイアログは `<dialog>` と `command="show-modal"`、ポップオーバーとメニューは `popover` 属性と CSS anchor positioning、アコーディオンは `<details name>`、ツールチップは `popover="hint"` と `interestfor` で開閉します。開閉のために状態管理や JavaScript を足さないでください。`Dialog.Trigger`・`Popover.Trigger`・`Menu.Trigger`・`Tooltip.Trigger` が要素同士を結び付けます。
- ランタイムは必要に応じて追加します。`<UrushiRuntime />` をルートに 1 つ置くと、メニューとタブのキーボード操作、Chromium 以外でのツールチップとホバーカード、トーストが加わります。置かなくても、コンポーネントは表示され、開閉もできます。
- CSSで実装できる動きにJavaScriptを追加しないでください。出入りのアニメーションは `@starting-style`、位置合わせは `position-area`、背景のスクロール止めは `:has(:modal)` です。
- 見た目はパックで指定します。コンポーネントの色・角・余白・文字の大きさを `className` や `style` で上書きしないでください。上書きしてよいのは配置（外側の余白、幅、グリッド上の位置）だけです。別の見た目が必要なときは `variant` を使い、足りなければバリアントを追加します。
- 1つの範囲には1つのパックを適用します。ページ全体は `<html data-pack="graphite">` で決め、一部だけ変えるときは `data-pack="lucent"` を付けた要素で囲みます。1 つのコンポーネントの中でパックを混ぜないでください。
- 要素はidで結びます。HTML の `<label for>` と同じように、`Dialog.Trigger dialog="id"` と `<Dialog id="id">`、`Popover.Trigger popover="id"` と `<Popover id="id">`、`Menu.Trigger menu="id"` と `<Menu id="id">`、`Tooltip.Trigger tooltip="id"` と `<Tooltip id="id">` を同じ id で結びます。入力欄のラベル・説明・エラーは `Field` が結びます。

## 文章の書き方

- 本文は「です・ます」で書き、何をするのかが伝わる述語まで書きます。体言止めや倒置で強調したり、読点で不要な間を作ったりしません。
- 見出しには、その箇所で扱う内容や操作を具体的に書きます。ボタン名や表の項目名は短く保ちます。
- ボタンには押すと何が起きるかを動詞で書きます（「保存」「タスクを追加」「削除する」）。「OK」「はい」は使いません。同じ操作は流れの最後まで同じ言葉にします。
- 確認ダイアログの見出しは問いの形にします（「「秋のキャンペーン」を削除しますか？」）。説明文には、何が起きるかを具体的に書きます（「タスク 5 件とコメントがすべて消えます。」）。
- エラーには起きたことと修正方法を書きます。謝罪の言葉や曖昧な表現は入れません。
- 英数字は半角です。和文と英数字のあいだの空きは `text-autospace` が付けます。
- 絵文字や感嘆符で飾りません。

## 色

- 色はすべてトークンで指定します。生の色の値（`#fff` や `oklch()`）を直接書かないでください。
- 背景は `ur-color-bg`、面（パネルやカード）は `ur-color-surface`、オーバーレイ（ダイアログやポップオーバー）は `ur-color-surface-overlay` です。
- 本文は `ur-color-text`、補足は `ur-color-text-muted`、注記や日付は `ur-color-text-subtle` を使います。3 つとも、`ur-color-bg` と `ur-color-surface` の上で 4.5:1 以上のコントラストがあります。
- 主な操作は `ur-color-action` で、その上の文字は `ur-color-on-action` です。主ボタンは 1 つの画面に 1 つだけにします。
- `ur-color-accent` は、フォーカス・選択・進行中といった「状態」にだけ使います。装飾には使いません。
- `ur-color-danger` は、削除などの取り消せない操作と、期限切れの表示にだけ使います。
- Graphite は色を抑えたパックです。主ボタンは墨色（`ur-color-action`）にし、フォーカスや選択には落ち着いた緑を使います。Lucentは主な操作とアクセントに青を使います。成功・注意・危険の色は、それぞれの状態を伝えるために使います。
- ダークモードは `data-theme="dark"` で切り替えます。何も指定しなければ OS の設定に従います。Graphite のダークモードでは、主ボタンが明るい色に反転します。

## 書体

- コンポーネントの書体は `ur-font-family-ui` を使います。英数字はInter、日本語はNoto Sans JPを優先し、未読み込みならシステムの書体へ切り替わります。ウェイトは400（本文）、500（ボタン・ラベル）、600（コンポーネントの見出し）が基本です。
- サイトの見出しやワードマークは、コンポーネントとは別に設計しています。サイトの文字装飾をコンポーネントの内部へ持ち込まないでください。
- 本文の行間は 1.75、見出しは 1.5 前後にします。ページの大見出しは 1.22 まで詰めます。
- 見出しには約物を詰める指定（`font-feature-settings: "palt"`）を付け、`word-break: auto-phrase` で文節の途中では改行しないようにします。本文には palt を付けません。
- 数字が縦に並ぶ場所（期限、件数、金額）は `font-variant-numeric: tabular-nums` で桁をそろえます。
- 文字の大きさは書体スタイル（`display`、`heading`、`title`、`body`、`control`、`small`）から選び、その間の値は使いません。

## 余白とレイアウト

- Cardの内側の余白はsmが16px、mdが24px、lgが32pxです。見出しと操作の間隔を保ちます。
- 余白は `ur-space-1`〜`ur-space-6`（2・4・8・12・16・24px）の段階から選びます。コンポーネントどうしの間隔は `gap` で取り、個々の要素に margin を付けません。
- 文章は左揃えにします。1 行は全角 35〜40 字（約 32em）までにします。
- 区切りは線を足すより、まず余白で表します。線を使うときは `ur-color-border`（1px）にします。

## 角と形

- 角丸はパックごとに決まっています。Graphiteではコンポーネントが8px、面が12px、オーバーレイが10px、ダイアログが16pxです。Lucentは10・16・12・20pxで、スクワークル対応時は12・19・14・24pxになります。
- 1 つの画面の中で、角丸の大きさを自分で変えないでください。

## 面と影

- Graphiteの面は不透明にします。縁は `ur-shadow-panel` の 1px の輪で表し、オーバーレイだけに柔らかい落ち影（`ur-shadow-overlay`、`ur-shadow-dialog`）を付けます。すりガラスは使いません。
- Lucentの面も不透明にし、文字を読みやすく保ちます。DialogやPopoverの表面には背景ぼかしを重ねません。
- 影の色やぼかしにはトークンの値を使ってください。

## 動き

- 動きは、利用者の操作で何が変わったかを伝えるためにだけ使います。ページを開いたときの演出や、装飾的なループアニメーションは入れません。
- Graphiteの動きは通常120ms、オーバーレイは160msです。通常のイージングは `cubic-bezier(0.2, 0, 0, 1)` です。
- Lucentの動きは通常160ms、オーバーレイは180msです。通常のイージングは `cubic-bezier(0.22, 1, 0.36, 1)` です。両パックとも、拡大して現れるコンポーネントは0.985倍から始まり、大きく弾ませません。
- Navigation Menuのパネル切替は、任意ランタイムがWeb Animations APIで補います。背景の位置・幅・高さを240msで変え、文字の大きさとDOMの順序は保ちます。短い間に切り替えても、途中の形から次へつなげます。動きを減らす設定では即座に切り替えます。
- 「動きを減らす」設定（`prefers-reduced-motion: reduce`）では拡大縮小をなくし、フェードだけにします。パックが自動で切り替えます。
- 閉じるときはGraphiteが120ms、Lucentが160msで応答します。閉じるアニメーションは、`overlay` に対応したブラウザだけで動きます。対応していないブラウザでは即座に閉じます。
- 状態の変化もCSSで表します。チェックの印は待ち時間を置かずに現れ、スイッチのつまみは押している間だけ2px伸びます。タブの下地は選んだタブへ滑り、消えるトーストは横に抜けて残りが詰まります。速さとイージングはパックに従います。
- 動きを減らす設定では、伸び縮み・滑り・畳み込みをすべて止め、フェードだけにします。
- 同じ設定ではSpinnerの回転も止めます。処理中であることは、静止した印と読み上げ用のラベルで伝えます。
- 動きはブラウザの対応に合わせて段階的に付きます。タブの下地が滑るのは Chromium と Safari、トーストと Accordion の高さが動くのは Chromium です。対応していないブラウザでも、見た目と動作は崩れません。

## 状態

- ホバー：`ur-color-secondary-hover`、`ur-color-action-hover`、`ur-color-danger-hover`、`ur-color-ghost-hover`。
- 押下：パックの `press-scale` で、わずかに縮みます。
- フォーカス：`ur-color-focus-ring` の 2px の実線で、2px 離して表示します。すべての面に対して 3:1 以上のコントラストがあります。フォーカスの表示は消さないでください。
- 無効な状態では不透明度を0.4にします。押せない理由が分かるときは、無効にするより理由を書いてください。
- 処理中：`loading` を指定するとスピナーが出て、`aria-disabled` になります。フォーカスは外れず、フォームの二重送信も防ぎます。

## アクセシビリティ

- 入力欄と選択コントロールの枠は、両パックの明暗テーマで、field・background・surface・overlayの各色に対して3:1以上を保ちます。補足文は13pxです。
- Windowsのコントラストテーマなど、`forced-colors`が有効な環境ではシステムの色を使い、選択の印とフォーカスの輪郭を残します。
- ネイティブの要素がある場合は、それを使います（`<button>`、`<dialog>`、`<input type="checkbox">`）。`div` に `onClick` を付けてコンポーネントを作らないでください。
- ダイアログには必ず `title` を付けます。ポップオーバーには `title` か `aria-label` を付けます。
- 危険な操作の確認ダイアログでは、安全な側のボタン（キャンセル）に `autoFocus` を付けます。
- アイコンだけのボタンには `aria-label` を付けます。
- Safari では、マウスでクリックしてもボタンにフォーカスが移りません（Safari の標準動作）。キーボード操作でのフォーカスの戻り先は正しく動きます。

## アイコンとロゴ

- Phosphorのアイコンを52種類同梱しています。`@urushi/react/icons`から個別に読み込み、コンポーネントのchildrenやiconに渡してください。サイズは16・20・24pxから選べます。別のアイコンセットのSVGも使えます。
- 絵文字をアイコンの代わりに使わないでください。
- サイトでは、3本の線で組んだUのマークと小文字のワードマークを使っています。コンポーネントを使うアプリにUrushiのマークを表示する必要はありません。

## AI エージェントへ

- 画面を作る前に、使うパックとコンポーネントの組み合わせを決めてください。
- コンポーネントの props とバリアントは、各コンポーネントのページ（`components/<名前>/README.md`）にあります。そこに書かれていない props や値を作らないでください。
- 実際のプロジェクトでは `@urushi/eslint-plugin` が、見た目の上書き・生の色の値・必須パーツの欠けをエラーにします。エラー文に代わりの書き方が書いてあるので、それに従って直してください。
