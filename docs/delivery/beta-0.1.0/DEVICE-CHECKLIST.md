# 実機とスクリーンリーダーでの確認（0.1.0-beta.1）

自動テスト（axe、キーボード操作、3 つのブラウザエンジン、320px の表示）はすべて通っています。ここでは、人が実際に聞いて触らないと分からないことだけを確かめます。結果は表に ✓ か、実際に起きたことを書きます。

## 準備

1. サイトを作って、同じ Wi-Fi のスマホからも開けるように配信します。

   ```sh
   pnpm --filter site build
   node scripts/serve-static.ts apps/site/out 3200
   ```

   Mac では http://localhost:3200 を、スマホでは `http://<Mac の IP アドレス>:3200` を開きます（IP アドレスは `ipconfig getifaddr en0` で分かります）。
2. 各コンポーネントのページ（`/components/<名前>/`）の操作例で確かめます。Blocks の画面は `/blocks/<名前>/view/` です。
3. 読み上げはパックに関係しないので、Graphite だけで確かめれば足ります。

| 組み合わせ | 起動方法 | 優先度 |
|---|---|---|
| VoiceOver ＋ Safari（macOS） | ⌘F5 | 必須 |
| VoiceOver ＋ Safari（iPhone） | 設定 → アクセシビリティ → VoiceOver | 必須 |
| TalkBack ＋ Chrome（Android） | 音量キーの上下を 3 秒長押し | 必須 |
| NVDA ＋ Firefox / Chrome（Windows） | Ctrl＋Alt＋N | できれば |

## 結果の書き方

- 期待どおりなら ✓、違えば読み上げられた内容か、起きたことを書きます。
- 問題があった項目は、端末・OS・ブラウザ・スクリーンリーダーの版と再現手順を添えて、このファイルの末尾に足します。直したら CHANGELOG と COMPATIBILITY.md の「未検証」を更新します。
