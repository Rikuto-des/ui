# Checkboxと追加コンポーネントの改善

2026年10月29日。Checkboxのアニメーションを見直し、Slider、Carousel、Switchにも機能と動きを追加しました。

## 変更点

| コンポーネント | 実装した内容 |
| --- | --- |
| Checkbox | チェックの線を260msで描画し、押している間は少し縮みます。一部選択は横線で示します。ネイティブ入力、ラベル、フォームの動作は維持しました。 |
| Slider | `showValue`でつまみに追従する値、`valueSuffix`で単位、`marks`で直接選べる目盛りを追加しました。ドラッグ、矢印キー、目盛り、Reactの状態変更、フォームリセットが同じ値を表示します。 |
| Carousel | 全対応ブラウザで前後送り、位置への直接移動、現在位置表示を使えます。連続操作、RTL、Home / End、端でのフォーカス保持に対応しました。 |
| Switch | `showState`でトラックにオン・オフの記号を追加しました。詳細ページでは集中モードを切り替えると、通知の見本がまとまり、作業領域が広がります。 |

修正前のCheckboxは、実画面で120msのクリップ表示になっていました。今回はSVGの線を描く実装に変更し、3ブラウザでアニメーション途中の描画を検証しました。描画には追加のJavaScriptを使いません。動きを減らす設定では即座に切り替わります。

Sliderの追従表示・目盛り操作と、Carouselの共通操作ボタンには`UrushiRuntime`を使います。JavaScriptなしでもネイティブの範囲入力やスクロールは利用できます。外部のアニメーションライブラリは追加していません。

詳細ページは、Checkboxの公開前チェック、Sliderの文字サイズ・余白調整、Carouselのデザインノート、Switchの集中モードに作り替えました。一覧でもCheckboxの描画、Sliderの追従表示と目盛り、Carouselの送り操作を使えます。API契約、生成ファイル、説明も更新しています。

| 新機能のコンポーネント検証 | 6課題×Chromium・Firefox・WebKit、18件成功 |
| 既存コンポーネント・ネイティブ入力・前回のUXの回帰 | 204件成功 |
| 新しい詳細ページ、一覧、サイドバー | 36件成功 |
| Next.jsのSSR・JavaScript無効時・runtime | 36件成功 |
| 単体テスト | 284件成功 |
| 型検査・lint・生成・サイトビルド | 成功 |

操作テストは重複を除いて294件です。Sliderの指定幅とフォーム操作は、最後の配置修正後にも3ブラウザで再確認しています。

新しい詳細ページは320pxと1280px、ライトとダークで確認しました。axeの対象ルールで違反はありませんでした。一覧も既存の2パック・2テーマの表示検証を通過しています。テーマ切り替えの途中は色が補間されるため、コントラスト検査は切り替えが終わった状態で実施しました。

既存のTabs位置検査では、WebKitの微小な負の差を丸めた`-0`と`0`が不一致になりました。幾何学的な許容値を変えず、差の絶対値を比較するように修正し、3ブラウザで再確認しました。

アプリ内ブラウザでは、Checkboxの一部選択・全選択、Sliderのドラッグ・目盛り・リセット、Carouselの直接移動・連続送り、Switchの切り替えを実際に操作しました。319px幅では文字サイズと余白を最大にした表示も確認しています。今回の変更について、端末実機とスクリーンリーダーでの検証は未実施です。

途中で保存領域が不足したため、この作業で再生成できるNext.jsのビルドキャッシュを整理して検証を続けました。ソース、依存関係、既存の比較資料は削除していません。AI比較とサイズ測定は今回再実行していません。
