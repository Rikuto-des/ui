# 日本語の文章を見直した記録

2026年10月29日に、サイトの日本語をyomiyasuの方針に沿って読み直しました。トップページ、一覧、52コンポーネントのデモと利用ガイド、ドキュメント、デザイン規約を対象にしています。143ファイルを確認し、122ファイルの文章を修正しました。

## 修正した内容

説明文は何ができるかが伝わる語順に直し、述語まで書きました。体言止めや倒置で強調する表現、短い句を読点で区切る表現を減らしています。ボタン名や表の項目名など、短く書く必要がある箇所は用途に合わせています。

| 修正前 | 修正後 |
| --- | --- |
| 項目を行き来して、動きを試す。 | 項目を切り替えて動きを試せます。 |
| 観察から、かたちへ。 | 観察を形にする |
| 日付、リンク、表記を確認。 | 日付やリンク、表記を確認します。 |
| 公開まで、あと4つ。 | 公開までに残っている4つの作業 |

デザイン規約にも本文と見出しの書き方を追加しました。「アイコンは未同梱」「DatePickerは今後追加」といった古い記述や、CardとTextareaの説明も現在の実装に合わせています。

比較ページ、AIの説明、トップページの実測値と試行条件は維持しました。既存の評価記録は変更していません。TypeScriptの構文を比較した範囲でも、日本語の表示文字列とJSX本文以外に変更はありません。

## 確認した結果

- 最終版のサイトビルドが通りました。型検査とLintも通っています。
- Chromium、Firefox、WebKitで267件のブラウザテストが通りました。うち264件はサイト全体の表示・操作・アクセシビリティ、3件は表示文言を更新したLinkの操作テストです。
- 全52コンポーネントの詳細プレビューを、Graphite／Lucentとライト／ダークの組み合わせで検査しました。320px幅でのはみ出しとaxeの違反は検出されていません。一覧プレビューも狭い画面とデスクトップで確認しています。
- 実画面ではIconsの保存切り替え、CheckboxのクリックとSpace操作、FileInputの見本表示と個別取消、Navigation Menuのサブメニューを操作しました。トップページとAIの説明も読み直しています。
- 最後にAIページのFieldの制約を明記し直し、再ビルド後の画面で確認しました。

文章の自然さは読み直して判断しました。自動テストが文章の品質を保証するものではありません。今回の画面確認はMac上のブラウザで行っており、実機のiPhone／Androidやスクリーンリーダーでの確認は含みません。

ログと画面は[copy-review](copy-review/)に保存しています。
