# 08. 数字で見る UI ライブラリの勢い：npm と GitHub（2026-10-22 時点）

生データとスクリプトは [data/](data/) に置いた。取得方法は最後の「取得方法と注意」にまとめてある。

## 読み方の前提

- **npm の DL 数は、そのまま比べても意味がない。**
  - npm 全体が 1 年で数倍に膨らんでいる。週間 DL で見ると、React は 1 年で +396%（45.3M → 224.4M）、TypeScript は +289%、lodash は +172%。
  - そのため本書では、各ライブラリが乗っている**フレームワークの伸びと比べてどうか**（「FW 比」）を主な指標にする。
  - 「‰」は、React の DL 1,000 回あたりに何回 DL されているかを表す。
- **欠損している日がある。**
  - npm API は 10 日分、全パッケージで 0 を返していた。2026-10-12〜18 の週もそのうち 3 日が欠けていて、値は約 45% 少なく出る。
  - そこで週の比較には **2026-09-28〜10-04** の週を使い、1 年前・2 年前も同じ曜日の週と比べた。
  - 01〜07 のレポートの一部は 10/12〜18 の週の数字を使っているので注意すること。

## 1. 要約

- **一番伸びているのは shadcn エコシステム。**
  - shadcn CLI は週 13.36M。React に対する比率は 1 年で +716%、2 年で 3.2‰ → 55.2‰（17 倍）。
  - GitHub スターは +28.0k/年で、UI 系リポジトリの中で最多。
  - アイコンの lucide-react も、2 年で 69‰ → 578‰（約 8 倍）。
- **ヘッドレス層は Radix から Base UI への交代が始まった。**
  - @base-ui/react は公開から 9 か月で週 19.27M。**2026-09-21 の週に radix-ui 統合パッケージ（19.06M）を上回った。**
  - 直近 3 か月の React 比は、Base UI が +88%、radix-ui が +31%、@radix-ui/react-slot が −10%。
  - スターは base-ui が +5.1k/年（+85%）、primitives（Radix）が +1.4k/年（+8%）。
- **旧パッケージから新パッケージへの移行は、ほとんどが終わりかけている。** 2026-09 時点での「新側のシェア」は次のとおり。

  | 新 | 旧 | 新側のシェア |
  |---|---|---|
  | tw-animate-css | tailwindcss-animate | 64% |
  | motion | framer-motion | 32% |
  | @heroui/react | @nextui-org/react | 89% |
  | webawesome | Shoelace | 92% |
  | shadcn | shadcn-ui | 98% |

- **失速しているのは、スタイル込みの大型ライブラリと CSS-in-JS。** 2 年間の React 比シェアの変化は次のとおり。

  | パッケージ | 2 年前 → 今 |
  |---|---|
  | @mui/material | 162‰ → 59‰ |
  | antd | 60‰ → 21‰ |
  | @headlessui/react | 78‰ → 41‰ |
  | styled-components | 216‰ → 64‰ |
  | @emotion/react | 326‰ → 119‰ |

- **AI 向け UI が新しく伸びている層。**
  - MCP Apps（ext-apps）は公開 10 か月で週 5.32M。
  - @json-render/core は週 2.35M で、直近 3 か月の React 比 +126%。
  - streamdown は週 8.12M、@assistant-ui/react は週 2.37M。
  - 一方で、ChatKit は直近 3 か月で −57%（DL 数そのもの）、A2UI は React 比 −20% と落ちている。
- **shadcn の「全部入り」依存が頭打ちになっている。**
  - 対象は vaul、input-otp、embla、cmdk、sonner。直近 3 か月の React 比は −17〜−22%。
  - これらは 2025-04 に一斉に約 7 倍に跳ねていた。AI のアプリ生成テンプレートがまとめて入れていたものが頭打ちになったと推測している（未検証）。
- **スターの勢いはアニメーション系のコンポーネント集に集中している。**
  - react-bits は +21.1k/年。
  - motion-primitives は加速度 2.39。animate-ui、ReUI、Magic UI は 1.27〜1.35 で加速中。
- **モバイルは「React Native 上の Tailwind」と「OS ネイティブ UI」に二分されつつある。**
  - uniwind 週 843k、@expo/ui 週 5.62M（1 年前は 10k）、heroui-native 週 215k。
  - tamagui は React Native 比で −32%（年）。

## 2. カテゴリ別の表

表の列の意味:

- **週 DL**: 今 = 2026-09-28〜10-04、1 年前 = 2025-09-29〜10-05、2 年前 = 2024-09-30〜10-06。
- **FW 比（年）**: 1 年間の伸び率を、土台のフレームワークの伸び率で割り、1 を引いた値。0% ならフレームワークと同じペース、プラスならそれより速い。土台は次の記号で示す。

  | 記号 | フレームワーク | 1 年の伸び |
  |---|---|---|
  | R | react | +396% |
  | RN | react-native | +346% |
  | Vue | vue | +189% |
  | Sv | svelte | +291% |
  | Solid | solid-js | +748% |
  | Ng | @angular/core | +83% |
  | TS | typescript | +289% |

- **直近 3 か月**: 2026-09-21〜10-04 の 2 週間を、2026-06-22〜07-05 の 2 週間と比べたもの。「DL 数そのものの伸び → FW 比」の順に書いた。同じ期間に react は +49% 伸びている。
- **★+365 日**: Best of JS の日次データから計算した、直近 1 年のスター増加数。
- **※**: 1 年前の値に一時的な急増（スパイク）があり、前年比が歪んでいるもの。

## 4. 急伸と失速

### 急伸

- **shadcn**
  - React 比シェアは 3.2‰ → 8.6‰ → 55.2‰（2024-10 → 2025-10 → 2026-09）。
  - スターも +28.0k/年で、UI 系の 1 位。
- **AI 向け UI**
  - 直近 3 か月の FW 比は、json-render +126%、ext-apps +82%、streamdown +48%、ai +41%、use-stick-to-bottom +43%。
  - React 比シェアでは、ai が 16‰ → 146‰ と大きく伸びた一方、@ai-sdk/react は 14‰ → 48‰ にとどまる。UI のフックより、サーバー側・エージェント側での利用のほうが速く伸びている。
- **アイコン**
  - lucide-react は 578‰ で圧倒的。
  - @hugeicons/react（+108%）と @phosphor-icons/react（+92%）が急伸している。
  - react-icons と heroicons は縮小している。
- **アニメーション**
  - motion は FW 比 +172%（年）。GSAP はスターの加速度 1.64。
  - コンポーネント集では、react-bits と motion-primitives。
- **少数の大口利用者が DL を押し上げているとみられるもの**
  - 対象: @adobe/react-spectrum（22k → 1.80M）、react-aria（26.8‰ → 52.1‰）、@kobalte/core（56k → 2.81M）、@expo/ui（10k → 5.62M）。
  - 利用者の層が広がった結果とは限らない。

### 失速

- **スタイル込みの大型ライブラリ**: MUI、antd、Headless UI、Chakra（21.3‰ → 9.8‰）。Mantine は比較的踏みとどまっている。
- **CSS-in-JS**
  - styled-components は 216‰ → 64‰、emotion は 326‰ → 119‰。
  - スターの増加もほぼ止まっている。
- **shadcn の「全部入り」依存（2026-04 → 2026-09 の React 比シェア）**
  - vaul は 240‰ → 208‰、input-otp は 218‰ → 182‰、embla は 232‰ → 188‰、sonner は 321‰ → 283‰。
  - 一方、cva と tailwind-merge は横ばい。
- **その他**
  - モバイル: tamagui、react-native-paper
  - Svelte: melt-ui
  - 更新停止: tailwindcss-animate（最終 push 2024-07）
  - AI 向け UI: ChatKit、A2UI（スター数に対して利用の伸びが鈍い）
  - react-hook-form: 直近 3 か月の React 比 −15%

## 5. 数字から言えること

1. **配布は shadcn レジストリ方式が前提になる。**
   - shadcn CLI の React 比シェアは 2 年で 17 倍、旧 CLI からの移行は 98% 終わった。
   - スターの伸びも、shadcn 本体と shadcn 互換のコンポーネント集に集中している。
2. **土台は Base UI を第一に選び、Radix にも対応する。**
   - Base UI は 9 か月で radix-ui 統合パッケージと並んだ。
   - ただし Radix の個別パッケージは今も巨大なので、どちらにも差し替えられる設計にしておくのが安全。
   - React Aria も、react-aria-components が 14‰ → 25‰ と伸びている。
3. **スタイリングは Tailwind v4 と CSS 変数。実行時に CSS を作る CSS-in-JS は避ける。**
   - アニメーションは tw-animate-css と motion（framer-motion ではなく）を使う。
   - StyleX は伸び率は高いが、規模はまだ Tailwind の約 1.6%。
4. **見た目で差をつけるならアニメーション。** ただしスターは関心の量であって、採用の量ではない。
5. **AI 向け UI は伸びる余地が大きく、オープンな仕様を選ぶべき。**
   - 特定ベンダー専用の ChatKit は失速した。
   - MCP Apps と json-render が伸びている。
6. **AI のアプリ生成サービスに選ばれるかどうかで、DL 数が決まっている。**
   - 2025-04 に shadcn の依存が一斉に急伸し、2026-04 以降は頭打ちになっている。AI テンプレートの影響と整合する（推測）。
7. **他のフレームワーク版は、ヘッドレス層を移植する形が勝っている。**
   - reka-ui、bits-ui、shadcn-svelte、spartan が伸びている。
   - 1 つの実装で複数フレームワークに対応する Ark/Zag は、シェアを落としている。
